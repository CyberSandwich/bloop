# ADR 0001: stack

Status: accepted (provisional until the owner reviews it; the seams keep a reversal cheap)

## Context

bloop pairs a shared screen with a phone, then hands the screen one short-lived file link. It needs real-time pairing, a strict CSP on every response, EU data location, £0 running cost at MVP scale, and a full local run with no cloud account. It is built to last ten years: simplicity, maintainability and zero debt decide, not speed of first build. Evidence: the stack research (about 45 sources and a local Durable Object test) and the criteria below, which were written before reading the research's recommendation.

Runtime dependencies, the only npm packages `package.json` `dependencies` may hold (plus vendored `uqr`, one file in `public/js/vendor/`): <!-- runtime-deps -->`zod`, `oauth4webapi`<!-- /runtime-deps -->. Everything else is a dev dependency. All versions are pinned exactly in `package.json`.

Dev dependencies beyond the table: `wrangler` (run and deploy), `@cloudflare/workers-types` (Worker types), `@types/node` (types for tests and tools only; `tsconfig.node.json` keeps it apart from the Worker types, which clash), `vitest` and `fast-check`, `@vitest/coverage-v8` (`npm run test:cov`; unit coverage only, since Worker code under `wrangler dev` runs in workerd where V8 coverage cannot reach), `html-validate` (HTML lint), `size-limit` with `@size-limit/file` (the per-page JS budgets, plain files, no bundler), `esbuild` (minifies each served module, ADR 0011), `@playwright/test`, `@axe-core/playwright` and `@lhci/cli` (CI only). Each is a dev-only tool: remove it together with the script that calls it.

Asset tools outside npm: `tools/render-og.py`, `render-slides.py` and `subset-font.py` regenerate committed files (social image and touch icon, demo slide images, font subset); nothing in the build or CI runs them. They need Python 3 with `fonttools` and `brotli` (a throwaway venv; `docs/setup.md`), ImageMagick, poppler, `avifenc` and `cwebp`. Why: headless Chrome cannot start locally, and `fonttools` is the reference subsetter. Remove: delete a tool and keep its last output.

Client parts beyond the table: `public/js/core/loader.js`, the one loading part (design.md section 6, Loader), with `readAll`, which counts a `fetch` body against its `Content-Length`. The viewer draws a photo it read that way on a `<canvas>`: the CSP has no `blob:` (and stays without it), so script-held bytes can never become an `<img>`. Why: real progress on a slow photo, which an `<img>` cannot report, with no second download and no wider CSP. Replaces: the blurred thumbnail stand-in. Remove: set the view link as an `<img>` `src` again, and show the part indeterminate.

A guest's video plays in a native `<video>` on its view link, in the screen page on a live screen too (`viewer-video.js`, a lazy `import()` with its own size entry, so a session with no video loads none of it). Why: a window on the view link is a top-level document under its `sandbox` CSP, an opaque origin that the link's `Cross-Origin-Resource-Policy: same-origin` refuses, so it never plays; in the page it stays under `media-src 'self'` with no CSP change. Native controls over custom ones: no bytes and the engines' own keyboard and screen reader paths. Remove: drop the module and route a guest's view link back to the window.

## Rejected

- **Node container plus SQLite** (Hetzner or Fly): best exit path and no US provider, but it costs money from day one and is a single machine to patch. It remains the exit: the code is plain `fetch` and SQL, so only the Durable Object module would need rewriting.
- **Firebase:** proprietary SDK throughout, Blaze plan needs a card. **Supabase:** idle free projects pause.

## Revisit when

- a buyer requires UK-only processing (Cloudflare has no UK jurisdiction; Worker code and TLS run at the nearest edge);
- PowerPoint does not follow a redirect from the short file URL (M0 test T3): the open path then streams, and the privacy wording changes;
- Durable Objects pricing or terms change, or the free tier stops covering 100 sessions a day.
