Security

The screen never gets your account.

What the Screen Gets

  • The items you approve
  • A link to each, which expires

What Stays on Your Phone

  • Your account
  • Your other files
  • The PC holds a link to each item you approve, and each link expires.
  • Each code works once for 60 seconds, and the phone shows the room before Approve.
  • Each open ends by itself after 90 minutes and is logged for IT to export.
  • A downloaded copy can stay on the PC. See what can stay.

What the PC Holds

A session ID and a link to each approved item, in the browser's session storage. Each link expires. While a file is open, PowerPoint holds the copy it opened. PowerPoint may also get a Microsoft download link for the file, which can work for up to 1 hour.

What bloop Keeps

Your email, a OneDrive token, the ID of one folder, and a log of who opened which file where and when. No slide content, except a guest's upload, deleted when its session ends.

Permissions

bloop asks for read access to OneDrive. Microsoft grants that for the whole OneDrive; bloop reads one folder and logs every read. Where your tenant allows it, the app folder limits access at Microsoft's side, but then only files in that folder appear.

What Can Stay Behind

A downloaded copy, recent file names and opened tabs with their history can stay until the profile is wiped.

Threat Model

QR relay: the phone shows the room name and a match code before Approve. Shoulder surfing: the code works once and lasts 60 seconds. Forgotten session: it ends by itself after 90 minutes. Wrong screen: unregistered screens carry a warning. Lost phone: disconnect bloop from any device.

Revoking Access

The user disconnects bloop; an admin removes the app in Entra.

Status

No external audit yet. The source is public. Report a security issue: security.txt.
