Security

What the room PC can and cannot reach.

What the Screen Gets

  • The items you approve
  • A link to each, which expires

What the Screen Never Gets

  • Your accountNever
  • Your other filesNever
  • Each code works once for 60 seconds, and the phone shows the room before Approve.
  • Each open ends by itself after 90 minutes, or 60 in the demo, and is logged for IT to export.
  • A downloaded copy can stay on the PC. See what can stay.

What the PC Holds

A session ID and a link to each approved item, in the browser's session storage. While a file is open, PowerPoint holds the copy it opened. PowerPoint may also get a Microsoft download link for the file, which can work for up to 1 hour.

What bloop Keeps

Your email, a OneDrive token, the ID of one folder, and a log of who opened which file where and when. No slide content, except a guest's upload, deleted when its session ends.

Permissions

bloop asks for read access to OneDrive. Microsoft grants that for the whole OneDrive; bloop reads one folder and logs every read. Where your tenant allows it, the app folder limits access at Microsoft's side, but then only files in that folder appear.

What Can Stay Behind

A downloaded copy, recent file names and opened tabs with their history can stay until the profile is wiped.

Threat Model

QR relay: the phone also shows the screen's match code before Approve. Shoulder surfing: a seen code is spent or soon expires. Forgotten session: it ends by itself. Wrong screen: unregistered screens carry a warning. Lost phone: see Removing Access.

Removing Access

Once OneDrive is connected, tap Disconnect OneDrive on any phone while you approve: bloop deletes its stored access and every sign-in ends at once, a lost phone's included. You may also be able to remove bloop in My Apps (myapplications.microsoft.com); your IT team can remove it for everyone in Microsoft Entra.

Status

No external audit yet. The source is public. Report a security issue: security.txt.
